Running a check

State for a check

Each [^agecheck^] element has a check pending boolean, initially false.

Each {{Document}} has a pending agecheck element, an [^agecheck^] element or null, initially null. The pending [^agecheck^] element is the element whose check runs in the document.

The run a check algorithm

To run a check given an [^agecheck^] element |element|:

  1. If |element| is disabled, then return.
  2. If |element|'s [=agecheck/shared group=] is not the empty string, then return.
  3. If |element|'s [=agecheck/check pending=] is true, then return.
  4. Let |document:Document| be |element|'s [=Node/node document=].
  5. If |document|'s [=Document/pending agecheck element=] is not null, then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  6. If |document|'s [=node navigable=] is null, or is not a [=top-level traversable=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  7. If |element|'s [=relevant settings object=] is not a [=secure context=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  8. If |document|'s [=Document/active sandboxing flag set=] has the [=sandboxed modals flag=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  9. If |document|'s [=Document/origin=] is an [=opaque origin=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  10. Let |groups:ordered set| be the [=agecheck/requested groups=] of |element|.
  11. If |element|'s [=relevant global object=] does not have [=transient activation=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  12. [=Consume user activation=] of |element|'s relevant global object.
  13. Set |element|'s [=agecheck/check pending=] to true.
  14. Set |element|'s [=agecheck/check dropped=] to false.
  15. Set |document|'s [=Document/pending agecheck element=] to |element|.
  16. Run these steps [=in parallel=]:
    1. Let |answer:age check result| be the result of running [=ask the age source=] given |document|.
    2. If |answer| is [=age check result/declined=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=agecheck/finish a check=] given |element|, |groups|, the empty string, and |document|, and abort these steps.
    3. Let |group:string| be the empty string.
    4. If |answer| is an [=age range=], then set |group| to the result of [=choose a group=] given |groups| and |answer|.
    5. Let |shared:string| be the empty string.
    6. If |group| is not the empty string, and the user agent holds [=remembered consent=] for |document|'s site and |group|, then set |shared| to |group|.
    7. Otherwise, show a prompt that meets the [=prompt requirements=], and wait for the person to answer or close the prompt. Closing the prompt without agreeing leaves |shared| as the empty string. If |answer| is [=age check result/no age set=] and the person chooses an age bracket in the prompt, then set |group| to the result of [=choose a group=] given |groups| and the [=age range=] that the chosen bracket gives. If the person agrees to share, then set |shared| to |group|. If |shared| is not the empty string, then create a [=remembered consent=] record for |document|'s site and |shared|.
    8. [=queue an element task=] on the [=user interaction task source=] given |element| to [=agecheck/finish a check=] given |element|, |groups|, |shared|, and |document|.

Finishing a check

To finish a check given an [^agecheck^] element |element|, an ordered set |groups|, a string |shared|, and a {{Document}} |document|, where |document| is the document in which the check started and |groups| are the [=agecheck/requested groups=] of |element| when the check started:

  1. Set |element|'s [=agecheck/check pending=] to false.
  2. If |document|'s [=Document/pending agecheck element=] is |element|, then set it to null.
  3. If |element| is not [=connected=], or |element|'s [=Node/node document=] is not |document|, or |document| is not [=Document/fully active=], then [=fire an event=] named `error` at |element|, and return.
  4. If |element|'s [=agecheck/check dropped=] is true, then [=fire an event=] named `error` at |element|, and return.
  5. Let |currentGroups:ordered set| be the [=agecheck/requested groups=] of |element|.
  6. If |currentGroups| does not contain the same tokens as |groups|, in any order, then [=fire an event=] named `error` at |element|, and return.
  7. If |element| is disabled, then [=fire an event=] named `error` at |element|, and return.
  8. If |shared| is the empty string, then [=fire an event=] named `error` at |element|, and return.
  9. Set |element|'s [=agecheck/shared group=] to |shared|.
  10. [=Fire an event=] named `change` at |element|, with the {{Event/bubbles}} attribute initialized to true.

Event listeners during a check

While an element's [=agecheck/check pending=] is true, the user agent MUST run the [=agecheck/finish a check=] steps when the check ends, and MUST deliver the event that they fire to every event listener registered on the element, even when no script holds a reference to the element.

A user agent gets this by not garbage collecting the element while its [=agecheck/check pending=] is true. Without that, the steps might never run, the document's [=Document/pending agecheck element=] would stay set, and no later check in the document could start. The element's listeners could also be gone when the event fires.

HTML and other specifications give the same kind of guarantee for other objects with pending work, such as media elements, a `MessagePort` with a queued event, and an `EventSource` that is connecting.
