Running a check

State for a check

Each [^agecheck^] element has a check pending boolean, initially false.

Each {{Document}} has a pending agecheck element, an [^agecheck^] element or null, initially null. The pending [^agecheck^] element is the element whose check runs in the document.

The run a check algorithm

To run a check given an [^agecheck^] element |element|:

  1. If |element| is disabled, then return.
  2. If |element|'s meets age flag is true, then return.
  3. If |element|'s [=agecheck/check pending=] is true, then return.
  4. Let |document: Document| be |element|'s [=Node/node document|node document=].
  5. If |document|'s [=Document/pending agecheck element=] is not null, then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  6. If |document|'s [=node navigable=] is null, or is not a [=top-level traversable=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  7. If |element|'s [=relevant settings object=] is not a [=secure context=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  8. If |document|'s [=Document/active sandboxing flag set|active sandboxing flag set=] has the [=sandboxed modals flag=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  9. If |document|'s [=Document/origin=] is an [=opaque origin=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  10. Let |age: integer or failure| be the [=agecheck/requested age=] of |element|.
  11. If |age| is failure, then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  12. If |element|'s [=relevant global object=] does not have [=transient activation=], then [=queue an element task=] on the [=user interaction task source=] given |element| to [=fire an event=] named `error` at |element|, and return.
  13. [=Consume user activation=] of |element|'s relevant global object.
  14. Set |element|'s [=agecheck/check pending=] to true.
  15. Set |element|'s [=agecheck/check dropped=] to false.
  16. Set |document|'s [=Document/pending agecheck element=] to |element|.
  17. Run these steps [=in parallel=]:
    1. Let |result: age check result| be the result of running ask the age source given |age| and |document|. The |result| is one of "meets", "does not meet", "no age set", "declined", or "failed".
    2. If |result| is "declined", then [=queue an element task=] on the [=user interaction task source=] given |element| to [=agecheck/finish a check=] given |element|, |age|, false, and |document|, and abort these steps.
    3. Let |shared: boolean| be false.
    4. If |result| is "meets" and the user agent holds remembered consent for |document|'s site and |age|, then set |shared| to true.
    5. Otherwise, show a prompt that meets the prompt requirements for |result| and |age|, and wait for the person to answer or close the prompt. Closing the prompt without agreeing leaves |shared| false. If |result| is "meets" and the person agrees to share that they are at least |age|, then set |shared| to true.
    6. [=queue an element task=] on the [=user interaction task source=] given |element| to [=agecheck/finish a check=] given |element|, |age|, |shared|, and |document|.

Finishing a check

To finish a check given an [^agecheck^] element |element|, an integer |age|, a boolean |shared|, and a {{Document}} |document|, where |document| is the document in which the check started:

  1. Set |element|'s [=agecheck/check pending=] to false.
  2. If |document|'s [=Document/pending agecheck element=] is |element|, then set it to null.
  3. If |element| is not [=connected=], or |element|'s [=Node/node document|node document=] is not |document|, or |document| is not [=Document/fully active|fully active=], then [=fire an event=] named `error` at |element|, and return.
  4. If |element|'s [=agecheck/check dropped=] is true, then [=fire an event=] named `error` at |element|, and return.
  5. Let |currentAge: integer or failure| be the [=agecheck/requested age=] of |element|.
  6. If |currentAge| is not |age|, then [=fire an event=] named `error` at |element|, and return.
  7. If |element| is disabled, then [=fire an event=] named `error` at |element|, and return.
  8. If |shared| is false, then [=fire an event=] named `error` at |element|, and return.
  9. Set |element|'s meets age flag to true.
  10. [=Fire an event=] named `change` at |element|, with the {{Event/bubbles}} attribute initialized to true.

Event listeners during a check

While an element's [=agecheck/check pending=] is true, the [=agecheck/finish a check=] steps MUST run when the check ends. The event that they fire MUST reach every event listener registered on the element, even when no script holds a reference to the element.

A user agent gets this by not garbage collecting the element while its [=agecheck/check pending=] is true. Without that, the steps might never run, the document's [=Document/pending agecheck element=] would stay set, and no later check in the document could start. The element's listeners could also be gone when the event fires.

HTML and other specifications give the same kind of guarantee for other objects with pending work, such as media elements, a `MessagePort` with a queued event, and an `EventSource` that is connecting.
