Form reset and page lifecycle

Each [^agecheck^] element has a check dropped flag, initially false. The steps in this section set the flag to true when a running check must not succeed.

Reset

The agecheck reset algorithm is the reset algorithm for [^agecheck^] elements. Given an [^agecheck^] element |element|:

  1. If |element|'s [=agecheck/check pending=] is true, set |element|'s [=agecheck/check dropped=] flag to true.
  2. Set |element|'s [=agecheck/meets age=] flag to false.

Back/forward cache

In [=Document/reactivate|reactivate a document=], a new step goes right after the step that resets form controls whose autofill field name is "off", and before the step that fires `pageshow`:

For each [^agecheck^] element whose node document is |document|, invoke the reset algorithm for that element.

The step covers elements that are not connected, since script can still hold them.

Navigation and unloading during a check

HTML's [=unloading document cleanup steps=] gain these steps, given a `Document` |document|:

  1. Let |element| be |document|'s [=Document/pending agecheck element=].
  2. If |element| is not null:
    1. Set |element|'s [=agecheck/check dropped=] flag to true.
    2. The user agent MUST close any prompt that the check shows, and MUST NOT show a prompt for the check afterward.

Closing the prompt this way counts as the person closing the prompt without agreeing.
