Automated testing

This section defines an extension module for the [[webdriver-bidi]] specification. Browsers and sites can use the module to test the [^agecheck^] element without a real person or a real age. Support for the module is OPTIONAL for a [=user agent=].

The ageCheck module

The `ageCheck` module contains a command that sets a virtual age source behavior. While a virtual age source behavior is set, a check talks to neither the platform nor the person. The user agent answers both the age source and the prompt from the behavior instead.

Types 

        ageCheck.VirtualAgeSourceAction = "meets" / "does-not-meet" / "no-age-set" / "declined" / "failed" / "wait" / "clear"

        ageCheck.VirtualPromptAction = "share" / "cancel"

        ageCheck.SetVirtualAgeSourceBehaviorParameters = {
          action: ageCheck.VirtualAgeSourceAction,
          ? prompt: ageCheck.VirtualPromptAction,
          ? context: browsingContext.BrowsingContext,
        }

Each {^ageCheck.VirtualAgeSourceAction^} value says how ask the age source answers:

`"meets"`
The age source reports that the person is at least the age the check asks about.
`"does-not-meet"`
The age source reports that the person is younger than the age the check asks about.
`"no-age-set"`
The age source reports that the person has no age set.
`"declined"`
The age source reports that the person declined in the platform's own prompt.
`"failed"`
The age source reports a failure.
`"wait"`
The age source does not answer until the test sets another behavior for the same context. The waiting check then continues with that behavior. Until then the check stays pending, so a test can observe what happens while a check runs.
`"clear"`
The command removes a [=virtual age source behavior=].

Each {^ageCheck.VirtualPromptAction^} value names what the virtual person does when the user agent's prompt appears:

`"share"`
The virtual person agrees to share. Where the prompt says the age cannot be shared, the virtual person closes the prompt instead.
`"cancel"`
The virtual person cancels the prompt.

The ageCheck.setVirtualAgeSourceBehavior command

Command Type 
            ageCheck.SetVirtualAgeSourceBehavior = (
              method: "ageCheck.setVirtualAgeSourceBehavior",
              params: ageCheck.SetVirtualAgeSourceBehaviorParameters
            )
Return Type 
            ageCheck.SetVirtualAgeSourceBehaviorResult = EmptyResult

Each WebDriver [=session=] has a map of virtual age source behaviors, keyed by browsing context ID, and a default [=virtual age source behavior=]. Both start empty. A behavior is a pair of an action and a prompt action.

The [=remote end steps=] for the `ageCheck.setVirtualAgeSourceBehavior` command, given |session| and |command parameters|, are:

  1. Let |action: VirtualAgeSourceAction| be |command parameters|["`action`"].
  2. Let |prompt action: VirtualPromptAction| be |command parameters|["`prompt`"] if present, and `"share"` otherwise.
  3. Let |context: BrowsingContext| be |command parameters|["`context`"] if present, and `null` otherwise.
  4. If |context| is not `null`:
    1. Let |navigable: navigable| be the result of [=trying=] to [=get a navigable=] with |context|.
    2. If |navigable| is not a [=top-level traversable=], return an [=error=] with [=error code=] [=invalid argument=].
  5. If |action| is `"clear"`:
    1. If |context| is not `null`, remove the entry for |context| from |session|'s map of virtual age source behaviors.
    2. Otherwise, clear |session|'s map of virtual age source behaviors and set |session|'s default [=virtual age source behavior=] to `null`.
    3. Return [=success=] with data `null`.
  6. Let |behavior: pair| be the pair (|action|, |prompt action|).
  7. If |context| is not `null`, set |session|'s map of virtual age source behaviors[|context|] to |behavior|.
  8. Otherwise, set |session|'s default [=virtual age source behavior=] to |behavior|.
  9. Return [=success=] with data `null`.

Using the virtual behavior during a check

To get the virtual age source behavior for a {{Document}} |document|:

  1. If the user agent's webdriver-active flag is false, return `null`.
  2. Let |context ID: string| be the ID of |document|'s [=node navigable=]'s [=navigable/top-level traversable=].
  3. Let |session: session| be the current WebDriver [=session=].
  4. If |session|'s map of virtual age source behaviors contains |context ID|, return that entry.
  5. Return |session|'s default [=virtual age source behavior=].

When a [=virtual age source behavior=] applies to a check and the check reaches the user agent's prompt, the user agent MUST NOT show the prompt to a person. The user agent instead answers the prompt with the behavior's prompt action. The rules in prompt requirements do not apply to that answer.
